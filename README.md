# 🧮 Calculadora en Python

## 📖 Descripción
Este proyecto es una **calculadora de consola desarrollada en Python** como práctica de programación estructurada y control de versiones con GitHub.  
La aplicación ya es **funcional**, permitiendo realizar operaciones matemáticas básicas mediante un menú interactivo pero no centa con validaciones.  

Se utiliza como ejercicio para reforzar conceptos como:
- Bucles (`while`, `for`)
- Control de flujo (`match-case`)
- Control de versiones

---

## ⚡ Funcionalidades actuales
- Suma de varios números
- Resta
- Multiplicación
- División
- Potenciación

---

## 🚀 Futuras mejoras
Este proyecto seguirá evolucionando con nuevas características:
- Validaciones más robustas para entradas incorrectas
- Refactorización en funciones para mayor claridad y reutilización
- Historial de operaciones realizadas
- Interfaz gráfica (GUI) para una experiencia más amigable
